Detailed Description

Fixed-capacity result container for multi-pin read operations.

Stores up to 16 pin/value pairs on the stack, avoiding heap allocation. The PCAL95555 has exactly 16 GPIO pins, so 16 is the hard upper bound.

Supports range-based for loops and structured bindings:

auto results = driver.ReadPins({0, 5, 10});
for (const auto& [pin, value] : results) {
printf("Pin %d: %s\n", pin, value ? "HIGH" : "LOW");
}
